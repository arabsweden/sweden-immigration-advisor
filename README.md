```sh
npm ci
npm run dev
```

## حدود النسخة العامة

الواجهة والأقسام المحلية منشورة على GitHub Pages. المستشار الذكي يحتاج خدمة Gemini آمنة على خادم قبل تفعيله. لم يُرفع .env.local ولا يُضمّن مفتاح API في ملفات المتصفح.

نقل التطبيق لا يعني التحقق من صحة المعلومات القانونية أو حداثتها. راجع المصادر الرسمية قبل الاعتماد عليها.

## النشر

GitHub Actions يبني التطبيق وينشره عند تحديث main. مصدر Pages هو GitHub Actions.
